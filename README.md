# Skill Gaming — сайт клуба

Гоночные симуляторы и компьютерный клуб, Волгоград, Краснознаменская улица, 6 (цокольный этаж), круглосуточно.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная: симуляторы, четыре зоны, полный прайс, схема кокпита, сценарий заезда, ответы на вопросы, бронь, контакты |
| `simulators.html` | Гоночные симуляторы: ощущения, форматы визита, трассы и машины |
| `pc.html` | ПК-залы Standart и Pro, PlayStation 5, тарифы и пакеты |
| `privacy.html` | Политика конфиденциальности (черновик, ждёт реквизиты клуба) |
| `css/site.css` | Все стили |
| `js/site.js` | Вся логика: анимации, форма брони, меню, курсор |
| `img/` | Фотографии (webp), логотип, иконки |
| `fonts/` | Unbounded, Manrope, JetBrains Mono — локально, лицензии OFL внутри |
| `robots.txt`, `sitemap.xml` | Для поисковых систем |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

Сайт статический: никакой сборки, серверов и зависимостей. Открывается двойным кликом по `index.html`.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Сайт Skill Gaming"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Дальше: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`. Через минуту сайт поднимется.

При подключении своего домена замените адреса `https://skillgaming.ru/` в `sitemap.xml`, `robots.txt` и в теге `canonical` каждой страницы.

1. **Фотографии** — сейчас кадры с Яндекс.Карт, помечены подписями «заменим на съёмку клуба». Файлы в `img/`, имена сохранить
2. **Прайс** — взят с плаката клуба и карточки на картах, подтвердить актуальность
3. **Конфигурации ПК** — данные из справочника Langame, подтвердить
4. **Реквизиты** — в `privacy.html` квадратные скобки: наименование, ИНН, срок хранения, номер счётчика Метрики
